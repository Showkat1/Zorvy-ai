## Method

Each case runs the production text pipeline in-process: `EvidenceExtractor.extract` -> `URLIntelligence.analyze` per URL -> `RiskEngine.calculate_risk`. No LLM, no network, no database, no randomness. The risk engine is deterministic and the URL analysis is pure Python, so repeated runs are stable.

## Honest limits

- The dataset is **28 hand-written cases**, not a sample of real traffic. It proves the engine behaves as specified; it does not estimate field accuracy.
- Labels were written by the project author. There is no inter-annotator agreement study and no held-out test set yet.
- The corpus is mixed: 20 Pakistan-flavoured cases plus 8 India-focused cases. There are no Indian-language (Hindi, Tamil, Bengali) cases yet, and the sample is far too small for per-market claims.
- Latency is a single-process measurement on the machine that generated this report. It excludes HTTP, database and upload time, and it is not a capacity or throughput claim.
- A high score means a communication warrants verification. It is not proof of fraud, and a low score is not proof of safety.
